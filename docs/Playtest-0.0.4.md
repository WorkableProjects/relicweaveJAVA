# 0.0.4 Playtest Checklist

Tick each box when it works. If something breaks, write down what you did and what happened.

Tip: a creative world with cheats on makes this faster. `/relicweave gate tp` takes you straight to The Vestige.

## Setup
- [ ] Build the jar (`gradlew build`) and launch Minecraft 1.20.1 with Forge and the mod.
- [ ] The game starts and you can create a new world.
- [ ] Load an old 0.0.3 world. Nothing is missing and you get the new guide book once.

## Controls and Curios
- [ ] *Options → Controls → Key Binds → RelicWeave* shows Activate Relic (`R`) and Cycle Relic (`Z`). You can rebind both.
- [ ] With Curios installed, `G` opens Curios and `Z` switches relics.

## Getting there
- [ ] Kill the Ender Dragon. You receive *The Vestige: A Traveler's Primer*. Read it.
- [ ] Craft a Threshold Sigil, 8 Concordance Frames and a Gate Keystone.
- [ ] Build the 3×3 gate and wake it with the sigil.
- [ ] Use the gate. You land on the Arrival Plaza.
- [ ] Use the Return Waystone. You end up back where you left.

## In The Vestige
- [ ] The sky, fog and music look and sound right.
- [ ] The phase name shows in the top-right corner.
- [ ] Visit a few biomes (`/relicweave world biomes` lists the nearby ones).
- [ ] Find and enter a structure (`/locate structure relicweave:waystone_monolith`).
- [ ] Fight a few different mobs. Each one shows a warning before it attacks.
- [ ] Hazards: the rift meter appears, starfall rings show before they hit, and gravity pushes are survivable.

## Bosses
- [ ] Find a Boss Altar (e.g. `/locate structure relicweave:glassroot_warren`) and use it. The boss appears with a health bar.
- [ ] Beat one boss. You get its drops and the advancement.
- [ ] Walk away from a boss. After about 30 s it heals and resets.

## Gear and relics
- [ ] Craft Concordant Alloy and smith a Netherite piece into Aetherforged. Its enchantments stay.
- [ ] Craft a Reliquary Loom and add an augment to a new relic. Remove it again.
- [ ] Use each new relic with `R`. Check the Surveyor's Lens outlines.
- [ ] Make one new enchantment book and one new infusion. They show up in JEI.

## Quests
- [ ] The Advancements screen has a *RelicWeave* tab and a *The Vestige* tab.
- [ ] Quests unlock as you do the steps above.

## Multiplayer (optional)
- [ ] Two players on a server can both travel to The Vestige and fight a boss together.
